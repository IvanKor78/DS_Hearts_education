# 🫀 Модель предсказания риска сердечного приступа

> Бинарная классификация для оценки вероятности возникновения сердечного приступа

---

## 🚀 Быстрый старт

1. Откройте файл `index.html` в браузере
2. Загрузите данные в формате **Excel** или **CSV**
3. Получите предсказания модели

---

## 📋 Требования к данным

### Обязательные поля

Для корректной работы модели входной файл должен содержать:

- **`id`** — уникальный идентификатор записи
- **15 признаков** (см. ниже)

### Числовые признаки (11)

| Признак | Описание |
|---------|----------|
| `BMI` | Индекс массы тела |
| `Sedentary Hours Per Day` | Часы сидячего образа жизни в день |
| `Systolic blood pressure` | Систолическое артериальное давление |
| `Diastolic blood pressure` | Диастолическое артериальное давление |
| `Heart rate` | Частота сердечных сокращений |
| `Triglycerides` | Уровень триглицеридов |
| `Cholesterol` | Уровень холестерина |
| `Blood sugar` | Уровень сахара в крови |
| `Exercise Hours Per Week` | Часы упражнений в неделю |
| `Sleep Hours Per Day` | Часы сна в день |
| `Age` | Возраст |

### Категориальные признаки (4)

| Признак | Описание |
|---------|----------|
| `Physical Activity Days Per Week` | Дни физической активности в неделю |
| `Stress Level` | Уровень стресса |
| `Diet` | Тип диеты |
| `Obesity` | Наличие ожирения |

## 📊 Метрики качества

### Основные метрики

| Метрика | Значение | Комментарий |
|---------|:--------:|-------------|
| **ROC-AUC** | 0.55 | Основная метрика оптимизации |
| **Recall** | 0.90 | Выявление 90% рисковых пациентов |
| **Precision** | ~0.36 | Доля верных срабатываний |

### Порог классификации

```
Порог отнесения к классу "1" (риск): 0.111
```

---

## ⚠️ Ограничения модели

> **Важно:** Модель обучена на данных невысокого качества

- При текущих настройках модель работает **немного лучше baseline**
- Низкий порог классификации обеспечивает высокий Recall (90%), но приводит к значительному числу **ложноположительных срабатываний**
- При настройке на 100% выявление рисковых пациентов количество ложных срабатываний существенно возрастает

---

## 🎯 Назначение

Модель оптимизирована для **максимального выявления пациентов с риском инфаркта** (высокий Recall), что является приоритетом в медицинской диагностике — лучше перепроверить здорового пациента, чем пропустить больного.
